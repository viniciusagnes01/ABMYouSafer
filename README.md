# YouSafer ABM Control Center v3

Site estático para apresentar a estratégia ABM da YouSafer em formato de painel de controle.

## O que mudou na v3

- Estrutura visual de painel de controle, com sidebar e módulos.
- Drawflow 3D/animado corrigido para não cortar no desktop e empilhar no mobile.
- Score ABM preservado exatamente como estava.
- Inclusão de temas de email, sequência Apollo/CRM, social separado por LinkedIn/Instagram/Facebook.
- Inclusão das 5 LPs por persona: CEO, Comercial, Produto/SVA, CS/Retenção e Financeiro.
- Inclusão da régua de CRM com disparos, gatilhos, campos obrigatórios e SLA.
- Responsividade revisada.

## Como rodar

Abra `index.html` no navegador ou publique em Netlify/Vercel.

## Deploy no GitHub

```bash
git clone -b V4-COMPANY https://github.com/viniciusagnes01/ABMYouSafer.git
cd ABMYouSafer
# copie os arquivos desta pasta para a raiz do repo
git add .
git commit -m "feat: add YouSafer ABM Control Center v3"
git push origin V4-COMPANY
```

Observação: os arquivos de fonte enviados pelo usuário não foram incluídos no pacote.
