# YouSafer ABM Control Center v7

Versão final refinada para apresentação: painel ABM responsivo, scrap + clusterização, seletor de persona, funil ABM, email por persona, redes sociais e artigos/SEO.

## Como abrir
Abra `index.html` no navegador ou publique via GitHub Pages/Netlify.

## Estrutura
- `assets/js/data.js`: conteúdo modular.
- `assets/js/app.js`: renderização e interações.
- `assets/css/styles.css`: layout e identidade visual.
- `assets/img/`: logo, mascote e mockups.
