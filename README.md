# YouSafer ABM Control Center v8

Versão refinada do painel ABM YouSafer com a nova regra de clusterização:

> Base de usuários define o tipo de ABM. Persona/cargo define a mensagem. Score/intenção define o timing comercial.

## Principais ajustes da v8

- Clusterização por tamanho estimado da base de assinantes.
- Tiers de base: Tier 1 Estratégico, Tier 2 Prioritário, Tier 3 Escalável e Nurture/Enriquecer.
- Score ABM preservado, sem alterar a lógica aprovada.
- Tabela de leads com base estimada, tier por base, score, rota e próximo passo.
- Simulador de lead com explicação da regra aplicada.
- Downflow atualizado para validar porte real antes da cadência.
- Funil ABM continua classificando 1:1, 1:poucos e 1:muitos.

## Observação operacional

As faixas de base no painel são hipóteses de priorização para demonstração e organização da rotina. Antes do acionamento comercial, validar porte real da conta em fontes públicas, CRM, Anatel, ZoomInfo, LinkedIn ou dados do cliente.

## Como abrir

Abra `index.html` no navegador ou publique em GitHub Pages / Netlify.
